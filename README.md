# WeatherFit

WeatherFit is a web application that recommends outfits based on real-time weather conditions and temperature.

Users can search for a region to check today’s or tomorrow’s weather and receive clothing recommendations tailored to weather, temperature, gender, and preferred style.

---

## Overview

- **Core Functionality:** Real-time location-based weather information and weather-driven outfit recommendations  
- **Goal:** Reduce decision fatigue when choosing outfits and provide intuitive styling suggestions  
- **Key Feature:** Integration of public weather APIs and map/location services for real-time recommendations  

---

## Tech Stack

### Frontend (WeatherFitFrontend)
- React + Vite  
- React Router DOM  
- styled-components  
- React Hooks  
- Axios  
- Developed using VSCode  
- Windows / macOS  

### Backend (WeatherFitBackend)
- Spring Boot  
- Java  
- Gradle  
- Spring Web  
- Spring Data JPA  
- Validation  
- Lombok  
- MySQL  
- External APIs:
  - Korea Meteorological Administration (KMA) Weather API  
  - Kakao Map / Local API  
- Developed using IntelliJ IDEA / Eclipse  
- Windows / macOS
